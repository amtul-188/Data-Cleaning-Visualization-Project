# Data-Cleaning-Visualization-Project
## 📌 Project Overview

This project focuses on cleaning, preprocessing, analyzing, and visualizing raw data using Python. The goal is to improve data quality by handling missing values, duplicates, and outliers, and to generate meaningful insights through Exploratory Data Analysis (EDA) and visualizations.

## 🎯 Objectives

* Clean and preprocess raw datasets.
* Handle missing values and duplicate records.
* Detect and remove outliers.
* Perform Exploratory Data Analysis (EDA).
* Create visualizations to identify trends and patterns.
* Generate insights for data-driven decision-making.

## 🛠 Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn

## 🔄 Data Cleaning Process

* Removed duplicate records.
* Handled missing values using mean and mode imputation.
* Detected and removed outliers using the IQR method.
* Saved the cleaned dataset for further analysis.

## 📊 Visualizations Created

1. Histogram Distribution Plots
2. Correlation Heatmap
3. Count Plot
4. Scatter Plot
5. Box Plot

## 📈 Key Insights

* Identified data distributions and trends.
* Analyzed correlations between numerical features.
* Detected outliers affecting data quality.
* Explored categorical feature distributions.

## ▶️ How to Run
